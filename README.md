# Mapa de fortalezas y focos de desarrollo

Cuestionario de autoevaluación de los 4 focos del rol de Jefatura de Proyecto
(Comercial y consultivo, Diseño instruccional, Gestión y ejecución, Reporte y análisis),
con evaluación de par y comparación de ambas miradas. MAS Consultores.

- Aplicación de un solo archivo (`index.html`), sin servidor ni dependencias.
- Las respuestas se guardan solo en el navegador de quien responde (`localStorage`);
  no se envían a ningún servidor.
- Publicada con GitHub Pages.
